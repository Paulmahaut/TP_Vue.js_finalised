# TP Vue.js - Mini boutique d'articles

App Vue 3 + Vue Router : affichage, recherche, ajout et suppression d'articles, panier, page admin protégée.

## Lancer le projet

```
npm install
npm run dev
```

## Pages

- `/` Accueil
- `/articles` Liste des articles (recherche + pagination)
- `/article/:id` Détail d'un article
- `/ajouter` Ajouter un article
- `/panier` Panier
- `/login` Connexion (fictive)
- `/admin` Administration (redirige vers /login si non connecté)
